**Reading:** on this series, in this configuration, Kronos-mini zero-shot had ~20% higher MAE than the naive random walk
(DM test p = 0.0019), and none of the models' directional accuracy was statistically different from 50%. ARIMA and drift
were statistically indistinguishable from naive. This matches the public community reports cited in
`docs/competitive-landscape.md`. It is one horizon, one config and one synthetic series, so it doesn't show that Kronos is generally worse.

## Leakage checks
Structural fold checks passed. The negative control (a deliberately leaky model) was **detected**, so the detector works.
Every model's forecasts were unchanged (max diff 0.0) when all bars after the origin were altered. No data-quality warnings.

## Reproducibility evidence
`quanteval reproduce` re-ran each evaluation from its manifest on the same input file (hash-checked). A crypto-data run was reproduced the same way privately; it isn't published here pending data-licensing review.
- Synthetic: predictions.csv sha256 `0511ac634a9f5b61450ea7eadfc2aa31dfb07ef21adc10434a1897fc818f2bd8` in both runs; all models max |diff| = 0.0; accuracy metrics identical.
- Kronos-mini reproduced bit-for-bit on the same machine, thread count and seed (documented tolerance is relative 1e-6). Bitwise equality across different CPUs or torch builds is not guaranteed and was not tested.
- Latency and wall time differ between runs by design and are excluded from the comparison.
